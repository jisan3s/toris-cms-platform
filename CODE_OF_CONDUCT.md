# Code of Conduct

## Our Standard

We expect contributors to:

- Communicate respectfully and clearly.
- Assume good intent and focus on technical outcomes.
- Accept feedback and iterate constructively.
- Avoid harassment, personal attacks, or discrimination.

## Scope

This applies to repository discussions, issues, pull requests, and related project spaces.

## Enforcement

Maintainers may edit/remove comments, close threads, or block participation for behavior that violates this policy.

## Reporting

For serious incidents, report privately to project maintainers.
